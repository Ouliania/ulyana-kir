# Структура кейсов (Case Blocks)

## Поля данных (на примере Grom.bike)

### `src/data/cases.ts` — мета-данные кейса

| Поле | Назначение | Пример |
|------|-----------|--------|
| `slug` | URL-идентификатор | `'grom-bike'` |
| `projectName` | Короткое имя для ссылок/подписей | `'Grom.bike'` |
| `url` | Ссылка на живой сайт | `'https://grom.bike/'` |
| `role` | **Чипсы-метки** (UX Strategy, Copywriting…) — показываются на карточках кейсов | `['UX Strategy', 'Copywriting']` |
| `tint` | Цветовой акцент карточки | `'yellow'` |
| `stack` | Технологический стек (только на странице кейса) | `{ en: 'Yandex Kit', ru: 'Yandex Kit' }` |
| `video` | Путь к видео в `/public` | `'/videos/grom-bike.mp4'` |
| `poster` | Постер для видео | — |
| `mediaAspect` | Ориентация медиа | `'landscape'` (по умолчанию) |
| `featured` | Показывать на главной | `true` |

### `src/i18n/cases.ts` — тексты кейса (RU + EN)

| Поле | Назначение | Пример |
|------|-----------|--------|
| `tag` | **Название услуги** (одно слово/фраза) | `'Yandex Kit'` |
| `project` | **Заголовок кейса** (полное название проекта) | `'Разработка сценария клиента до заявки'` |
| `problem` | **Проблема** (один абзац) | `'Клиент переходил с маркетплейса…'` |
| `solution` | **Решение** (массив строк, каждая = пункт) | `['Навигация каталога по целям…', …]` |
| `metrics` | **Метрики** (массив {value, label}) | `[{ value: '4×', label: '…' }]` |
| `result` | **Результат** (массив строк) | `['Понятный онлайн-магазин…']` |

## Где что показывается

| Компонент | `tag` | `role` | `project` | `problem` | `solution` | `result` | `stack` |
|-----------|:-----:|:------:|:---------:|:---------:|:----------:|:--------:|:-------:|
| **CaseCardList** (главная) | ✅ `.cs-service` | ✅ `.cs-chip` | ✅ `.cs-project` | ✅ | ✅ | ✅ | — |
| **CaseStackList** (главная) | ✅ `.csk-service` | ✅ `.csk-chip` | ✅ `.csk-project` | ✅ | ✅ | ✅ | — |
| **CasePage** (страница кейса) | ✅ `.service-name` | ✅ `.roles` | ✅ `.project-expanded` | ✅ | ✅ | ✅ | ✅ `.stack-line` |

## Ключевое различие

- **`tag`** = категория услуги (Yandex Kit, Telegram Mini App, UX бронирования…)
- **`role`** = чипсы-метки компетенций (UX Strategy, Copywriting, Custom Code…)

Не путать: `tag` — это **что за услуга**, `role` — **какими инструментами сделано**.
